# plans

## Cursor Cloud specific instructions

This repository is a **documentation / planning repository only**. It contains Markdown files (planning and research notes) and no application code.

- There is **no application, service, server, database, or port** to run.
- There is **no package manager, lockfile, or dependency manifest** (no `package.json`, `requirements.txt`, `pyproject.toml`, `go.mod`, etc.).
- There is **nothing to build, lint, or test** in the conventional sense, and no setup/bootstrap scripts.
- The update script is intentionally a no-op because there are no dependencies to install.

Development work here means reading and editing Markdown documents (e.g. files under `plans/`). To preview a document, render it with any Markdown viewer; no project tooling is required.
